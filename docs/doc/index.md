# `doc/__init__.py` — schema documentation

`seared.doc` writes a Markdown page for every `@seared` class in a module or
package, so a schema's docs come from the schema itself. It needs nothing
beyond the standard library.

```sh
seared-doc mypkg.models -o docs/models            # write the pages
seared-doc mypkg.models -o docs/models --check    # CI: fail if they've drifted
python -m seared.doc mypkg.models -o docs/models  # the same, without the script
```

```python
from seared.doc import build_docs, document

page = document(Reading)               # one class → Markdown
pages = build_docs('mypkg.models')     # {relative path: Markdown}, index.md included
```

## Two stages

Introspection and rendering are separate on purpose:

1. **[`introspect`](introspect.md)** reads a class into a `SchemaDoc`: its
   name, docstring and one `FieldDoc` per field. It knows nothing about
   Markdown.
2. **[`render`](render.md)** turns a `SchemaDoc` into a page, from small
   section functions that another renderer can recompose.

[`generate`](generate.md) runs the two over a whole package: it finds the
classes, mirrors the package tree, cross-links nested classes, builds
`index.md`, and checks for drift. It takes the per-class renderer as an
argument, which is how zeared generates its wire-aware pages through the
same pipeline.

## Public API

| Name | From | |
|---|---|---|
| `introspect(cls)` | [`introspect`](introspect.md) | a class → `SchemaDoc` |
| `is_seared_class(obj)` | [`introspect`](introspect.md) | whether `obj` is a decorated `@seared` class |
| `SchemaDoc`, `FieldDoc`, `EnumDoc`, `VariantDoc` | [`introspect`](introspect.md) | the intermediate model |
| `document(cls, *, link_for=…)` | [`render`](render.md) | a class → its Markdown page |
| `render_schema(schema, *, link_for=…)` | [`render`](render.md) | a `SchemaDoc` → its page |
| `render_header`, `render_fields_table`, `render_enums`, `render_variants` | [`render`](render.md) | the page's sections |
| `collect(target)` | [`generate`](generate.md) | every class reachable from a module or package |
| `build_docs(target, *, render_one=None)` | [`generate`](generate.md) | the whole doc set, in memory |
| `main(argv=None, *, render_one=None, prog=None)` | [`generate`](generate.md) | the CLI |

`document` and `introspect` are also re-exported at the package root, as
`s.document` and `s.introspect`.

## A generated page

```markdown
# Geo

A geo point.

## Fields

| field | wire key | type | required | default | notes |
|-------|----------|------|----------|---------|-------|
| `lat` | — | `float` | ✓ | — | degrees north |
| `lon` | — | `float` | ✓ | — |  |

_Generated by `seared.doc` — do not edit by hand._
```

A field's `doc=` becomes its notes; the class docstring, with Sphinx roles
stripped, becomes the page's text. See [`render`](render.md) for every
column and section.
