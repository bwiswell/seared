# `doc/render.py` — Markdown pages

Renders a [`SchemaDoc`](introspect.md) as a Markdown page. The page is
built from section functions, each returning a string (empty when it has
nothing to show), so another renderer can put its own sections around
them. zeared's wire-aware pages do exactly that.

## `document(cls, *, link_for=…)` and `render_schema(schema, *, link_for=…)`

`document` introspects a class and renders it; `render_schema` renders a
`SchemaDoc` you already have. A page is, in order:

1. **`render_header(schema)`:** `# Name`, then the docstring.
2. **`render_fields_table(schema, link_for)`:** the `## Fields` table.
3. **`render_enums(schema)`:** an `## Enumerations` member table per `Enum`
   field.
4. **`render_variants(schema, link_for)`:** a `## Variants` tag table per
   `Union` field, with its envelope and any fallback.
5. **The footer:** `_Generated by `seared.doc` — do not edit by hand._`

`link_for(cls) -> str` gives the link to another class's page. The default
is `'<Name>.md'`, beside this one; the generator passes one that follows
the package tree.

## The fields table

| Column | Shows |
|---|---|
| `field` | the attribute |
| `wire key` | the `data_key`, or `—` when it's the attribute |
| `type` | the annotation; a `T` field's links to its class's page |
| `required` | ✓ for `required=True`, and for every `Union`, since a missing or `null` tag always raises |
| `default` | the Python value an omitted field gets (`` `None` ``, never `` `null` ``), or `—` |
| `notes` | the field's `doc=`, then an `NDArray`'s "dtype: `float32`", then "nullable: `null` loads as `None`", then "not emitted (`dump=False`)", joined with `·` |

`|` is escaped in every cell, code included, so a `str | None` type
doesn't break the table, and a newline in a `doc=` becomes a space.
